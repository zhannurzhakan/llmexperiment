# Опыт 1: русский vs английский в токенайзере


## Токенайзер `cl100k_base`

| Фраза | Язык | Символов | Токенов | Символов/токен |
|---|---|---|---|---|
| Приветствие | RU | 12 | 7 | 1.71 |
| Приветствие | EN | 13 | 4 | 3.25 |
| Простая фраза | RU | 24 | 8 | 3.00 |
| Простая фраза | EN | 19 | 4 | 4.75 |
| Длинная фраза | RU | 84 | 39 | 2.15 |
| Длинная фраза | EN | 59 | 10 | 5.90 |

### Разбиение на токены

- **Приветствие / RU** — `Привет, мир!`  
  [Пр] [ив] [ет] [,] [ м] [ир] [!]
- **Приветствие / EN** — `Hello, world!`  
  [Hello] [,] [ world] [!]

**Приветствие: RU/EN = 1.75x**

- **Простая фраза / RU** — `Я люблю программировать.`  
  [Я] [ лю] [б] [лю] [ программ] [иров] [ать] [.]
- **Простая фраза / EN** — `I love programming.`  
  [I] [ love] [ programming] [.]

**Простая фраза: RU/EN = 2.00x**

- **Длинная фраза / RU** — `Большие языковые модели обрабатывают текст по кусочкам, которые называются токенами.`  
  [Б] [оль] [ши] [е] [ я] [з] [ы] [ков] [ые] [ мод] [ели] [ об] [\xd1\x80\xd0\xb0\xd0] [\xb1] [ат] [ыв] [а] [ют] [ текст] [ по] [ к] [ус] [оч] [к] [ам] [,] [ котор] [ые] [ н] [аз] [ыв] [а] [ют] [ся] [ т] [ок] [ен] [ами] [.]
- **Длинная фраза / EN** — `Large language models process text in pieces called tokens.`  
  [Large] [ language] [ models] [ process] [ text] [ in] [ pieces] [ called] [ tokens] [.]

**Длинная фраза: RU/EN = 3.90x**
